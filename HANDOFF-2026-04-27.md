## Key Technical Concepts

### Subscription Gate
```javascript
function _hasActiveGift(){
  const code   = localStorage.getItem('mth_gift') || '';
  const expiry = localStorage.getItem('mth_gift_expiry') || '';
  if (!code || !expiry) return false;
  return new Date().toISOString().slice(0,10) <= expiry;
}
```
Currently uses gift codes. When Omise is done, payment success writes to these same keys.

### Auth Flow (Supabase Email OTP)
1. User enters email → `showLoginOverlay()`
2. `_sb.auth.signInWithOtp({ email })` → Supabase sends OTP email
3. User enters 6-digit code → `_sb.auth.verifyOtp({ email, token, type:'email' })`
4. On success → `_sbSession` set → `_sbPull()` syncs profile from cloud → `_sbPush()` on changes

### i18n
`LANG` global = `'th'` or `'en'`. Set by `mth_lang` localStorage. `_applyLang()` function updates all UI text.
