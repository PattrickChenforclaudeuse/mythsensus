Foundationalฐานราก

Cosmic Score วัดอะไรกันแน่

Cosmic Score คือ ระดับ (level) — ตำแหน่งแบบ percentile ที่บอกว่าค่ากลาง (median) ที่ผสมจาก 26 ศาสตร์ของ chart คุณ อยู่สูงหรือต่ำแค่ไหนเทียบกับประชากรที่ทดสอบทั้งหมด มันคือสถิติแบบ "อันดับเชิงเปรียบเทียบ" ไม่ใช่เครื่องวัดความยิ่งใหญ่ และ — นี่คือจุดที่บทความเวอร์ชันก่อนหน้าเข้าใจผิด — มัน ไม่ใช่ เครื่องวัดว่า 26 ศาสตร์เห็นตรงกันมากแค่ไหน

ความเห็นตรงกันข้าม 26 ศาสตร์ยังมีอยู่จริงใน engine — มันคือสถิติจริงที่คำนวณแยกต่างหาก (ค่าการกระจายตัวข้าม 26 ระบบโหวต) แต่ตอนนี้มันอยู่ในฐานะเลนส์รองของตัวเอง เรียกว่า Consensus reading และมัน ไม่ได้ เป็นตัวกำหนด tier ที่คุณได้ tier ของคุณถูกกำหนดจากตำแหน่งบนเส้นระดับล้วน ๆ

ข้อควรรู้ตามตรง: ค่ากลาง (median) ที่ chart จริงส่วนใหญ่ตกอยู่นั้นแคบ — กว้างประมาณ 80 คะแนนเท่านั้น การแปลงช่วงแคบนี้เป็น percentile scale 300-999 จะขยายความต่างเล็ก ๆ ให้ดูใหญ่ขึ้น — คน 2 คนที่สัญญาณดิบใกล้เคียงกันมาก อาจตกคนละ tier ได้ ให้มอง tier เป็น อันดับเชิงเปรียบเทียบ ไม่ใช่ค่าความแม่นยำแบบสัมบูรณ์ — มันบอกแค่ว่าคุณอยู่ตรงไหนของประชากร ไม่ได้บอกว่าคุณมี "มากกว่า" หรือ "น้อยกว่า" แค่ไหนจริง ๆ

สามเลนส์อิสระ — ไม่มีเลขรวม "สุดท้าย" เลขเดียว

รายงานเวอร์ชันก่อนหน้าเคยผสม 3 คะแนนเป็นเลขเดียวเรียกว่า Cosmic Final (Soul Frequency × 40% + Life Terrain × 30% + Path Resonance × 30%). สูตรผสมนี้ถูกยกเลิกไปแล้ว — การรวม 3 คำถามที่ต่างกันเป็นเลขเดียวทำให้สิ่งที่แต่ละคะแนนบอกจริง ๆ พร่าเลือนไป โมเดลปัจจุบันแยกทั้ง 3 ออกจากกัน:

Cosmic Score (level) · Path Resonance (career fit) · Consensus reading แต่ละเลนส์ยืนอิสระและตอบคำถามคนละข้อ ไม่มีเลนส์ไหนถูกรวมเป็นเลข "สุดท้าย" เดียว — หน้าปกรายงานโชว์ Cosmic Score เป็นตัวเลขหลัก พร้อม Consensus bar อยู่ข้าง ๆ ในฐานะ reading แยกต่างหาก

🌌 Cosmic Score — ระดับของคุณ

ตัวเลขและ tier ที่บทความนี้อธิบายไปข้างต้น เป็นตำแหน่งแบบ percentile จากค่ากลางที่ผสมของ 26 ศาสตร์จากวันเกิดคุณ เทียบกับประชากร คงที่ตั้งแต่เกิด — ไม่ขยับหลังคำนวณแล้ว

🎯 Consensus reading — 26 ศาสตร์เห็นตรงกันแค่ไหน

สถิติการกระจายตัวแยกต่างหาก — คะแนนของ 26 ศาสตร์เกาะกลุ่มกันแน่นแค่ไหนรอบค่ากลางของคุณ Consensus สูงแปลว่าศาสตร์ต่าง ๆ ชี้ไปทิศทางเดียวกันเป็นส่วนใหญ่ Consensus ต่ำแปลว่าดึงกันไปคนละทาง เป็นข้อมูลที่มีประโยชน์จริง แต่เป็นเลนส์รอง ไม่ใช่ตัวเลขหลัก และไม่ได้เป็นตัวกำหนด tier ของคุณ

ทำไมความยิ่งใหญ่กระจายไปทุก tier

กลับไปดูที่ distribution bar — ดุลย์ Balance และ ปฐพี Earth รวมกันครองประมาณ 45% ของผู้ใช้ เป็นก้อนที่กว้างที่สุดของเส้นกระจายตัว นี่ไม่ใช่ bug มันคือหน้าตาของสถิติระดับแบบ percentile-normalized เวลาที่สัญญาณดิบส่วนใหญ่เกาะกลุ่มใกล้ค่ากลาง — กลางเส้นคือจุดที่ chart ส่วนใหญ่ตกอยู่ตามธรรมชาติ และ engine ไม่ rescale ออกเพื่อทำให้คนรู้สึกพิเศษ

ใช่ — ขนาดของแต่ละ band ประมาณ 3% + 12% + 15% + 20% + 25% + 15% + 10% = 100%. ป้าย "Top X%" ในรายงานเป็น cumulative threshold ซึ่งเป็นเหตุผลที่ดูเหมือนทับซ้อน: "Top 15%" ของ รัศมี Radiance หมายถึงคะแนน 890+ ทำให้คุณอยู่เหนือ 85% ของผู้ใช้ — Radiance เองคือประมาณ 12% แต่ ทิพย์ Divine 3% เหนือขึ้นไปก็เป็นส่วนหนึ่งของ "Top 15%" เดียวกันนั้นด้วย

ยังมีอีกจุด: รายงานโชว์ percentile เฉพาะบุคคล ที่แม่นยำ (เช่น "Top 6%") คำนวณตรงจากคะแนนเฉพาะของคุณ ไม่ใช่แค่ label ขั้นต่ำของทั้ง tier คน 2 คนที่อยู่ tier เดียวกันอาจเห็นตัวเลขเปอร์เซ็นต์ต่างกันเล็กน้อย

คะแนนนี้ไม่ได้วัดว่าศาสตร์ต่าง ๆ เห็นตรงกันหรอกเหรอ?

ไม่ใช่ — นี่คือความเข้าใจผิดที่พบบ่อยจากบทความ methodology เวอร์ชันก่อนหน้า ความเห็นตรงกันข้ามระบบยังมีอยู่จริงและยังคำนวณอยู่ แต่มันคือ Consensus reading ซึ่งเป็นเลนส์รองแยกต่างหาก Cosmic Score และ tier ของคุณมาจาก ระดับ — ตำแหน่งของค่ากลางที่ผสมเทียบกับประชากร — ไม่ได้มาจากว่า 26 ศาสตร์เกาะกลุ่มกันแน่นแค่ไหน

ทำไม marketing บอก 1-1,000 ถ้าคะแนนจริงกระจุกอยู่ tier กลาง ๆ?

1-1,000 คือช่วงที่โชว์ให้ผู้ใช้เห็น (ค่าต่ำกว่า 300 ถูกซ่อนไว้) แต่ค่ากลาง (median) ที่เป็น input ให้การคำนวณ percentile นั้นแคบโดยธรรมชาติ — การ average 26 ระบบที่อิสระบีบสัญญาณดิบเข้าหากลาง ทำให้การแปลงเป็น percentile ต้องยืดช่วงแคบนี้ให้ครอบคลุมช่วงที่โชว์ทั้งหมด นี่คือข้อควรรู้เรื่อง "ค่ากลางแคบ" ที่บทความพูดถึงไปแล้วข้างต้น — มองตัวเลขเป็นอันดับเชิงเปรียบเทียบ ไม่ใช่ค่าความห่างแบบสัมบูรณ์

Cosmic Score ของฉันเปลี่ยนตามเวลาไหม?

ไม่ Cosmic Score และ Path Resonance คำนวณจากวันเกิด — ไม่เปลี่ยน. ตัวเลขที่ เปลี่ยน รายวันคือ Daily Cosmic Weather snapshot และ Verdict tier (Peak / Normal / Caution) ซึ่งอ่านตำแหน่งดาวจริงเทียบกับ chart วันเกิดคุณ. ทั้ง 2 ระบบนั้นอยู่คนละส่วนของรายงานและไม่กระทบ Cosmic Score ของคุณ

Path Resonance ของฉันว่าง — ทำไม?

engine ไม่ยอม fabricate คะแนน Path Resonance ถ้าคุณไม่บอก domain หรือ industry. การ default ไปคู่ fallback จะให้ตัวเลขที่ไม่เกี่ยวกับอาชีพจริงของคุณ — แย่กว่าไม่มีตัวเลข. กรอก career field ที่เป็น optional ในฟอร์มหน้าแรกเพื่อดู Path Resonance ของคุณ

ถ้าฉันเปลี่ยนงาน Path Resonance เปลี่ยนไหม?

ใช่ — Path Resonance เป็นคะแนน fit ระหว่าง Day Master ที่ fix กับ domain × industry ปัจจุบัน เปลี่ยน input ตัวใดตัวหนึ่งแล้ว rerun รายงาน คะแนนจะ update สะท้อนคู่ใหม่ (Cosmic Score กลับกัน ไม่ขยับเลย). นี่คือคะแนน Mythsensus ตัวเดียวที่ตอบสนองต่อ input ที่เป็น "การตัดสินใจชีวิต" มากกว่า "ตำแหน่งดาว"

เทียบคะแนนกับคนอื่นได้ไหม?

ได้ — engine เป็น deterministic และ tier table เป็น global ดังนั้นคะแนน 2 คนเทียบกันได้ตรง ๆ. แต่การเทียบ Cosmic Score เชิงสังคมแบบที่คนเทียบ GPA มักพลาด point ตัวเลขอธิบายว่า สัญญาณ archetype ที่ผสมของคุณอยู่ตำแหน่งไหนเทียบกับประชากร, ไม่ใช่ "ใครดีกว่า". เพื่อน 2 คนที่คะแนนต่างกันมากมักมีจุดแข็งที่เสริมกัน — ระดับสูงกว่าไม่ได้แปลว่าเป็นคนที่ดีกว่า แค่ตำแหน่งต่างกันบนแกนสถิติแกนเดียว ใช้คะแนนเพื่อเข้าใจตัวเอง ไม่ใช่เพื่อจัดอันดับตัวเอง
