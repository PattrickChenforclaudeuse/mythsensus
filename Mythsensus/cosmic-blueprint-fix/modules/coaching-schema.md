## Module 1: Cosmic Health Coaching
**ไฟล์ template:** `coaching-template.html`
**Output:** `cosmic-coaching-[ชื่อ]-[วันเกิด].pdf`

### โครงสร้างรายงาน
1. **Grand Convergence** — สิ่งที่ทุกศาสตร์เห็นตรงกันเกี่ยวกับร่างกายและนิสัย (3–5 จุด)
2. **Action Plans** — คำแนะนำที่มี 9 ศาสตร์รองรับพร้อม science note
   - กฎ 24 ชั่วโมง (Decision Pause)
   - น้ำและธาตุที่ขาด
   - การออกกำลังกายตามธาตุ
   - แอลกอฮอล์/สารเสพติด (ตามธาตุ ไม่ตัดสินทางศีลธรรม)
   - การนอนและฟื้นฟู
   - วินัยทางความคิด
3. **Weekly Plan** — ตารางสัปดาห์แรกที่ทำได้จริง
4. **Progress Check** — คำถามติดตามผล 4 สัปดาห์

### หลักการสำคัญ
- ทุก action ต้องมี **ศาสตร์ที่รองรับ** อย่างน้อย 3 ศาสตร์
- ทุก action ต้องมี **science note** จากงานวิจัยจริง
- ใช้ภาษา "เชิญชวน" ไม่ใช่ "สั่ง"
- ไม่ตัดสินทางศีลธรรม — อธิบายเหตุผลทางธาตุและร่างกาย
- ต้องมี disclaimer สายด่วนสุขภาพจิต 1323 ที่ท้ายรายงาน

```
2. สร้าง ACTION PLAN ที่มีศาสตร์รองรับ 3+ ศาสตร์ต่อ action
3. ทุก action มีวิธีทำจริงที่เป็นรูปธรรม

5. ไม่อ้างดวงสั่ง — อ้างว่าธาตุและพลังงานของร่างกายต้องการ

```

## Module 2: Cosmic Finance Coaching
**ไฟล์ template:** `finance-template.html`
**Output:** `cosmic-finance-[ชื่อ]-[วันเกิด].pdf`

### โครงสร้างรายงาน
1. **Disclaimer** — ชัดเจนว่าไม่ใช่คำแนะนำทางการเงิน (บังคับ ลบไม่ได้)
2. **การลงทุน ≠ การพนัน** — ตารางเปรียบเทียบ (บังคับทุกรายงาน)
3. **Convergence** — ดวงบอกอะไรเกี่ยวกับพฤติกรรมทางการเงิน
4. **แผนการออม** — ระบบ 50/30/20 + เงินสำรอง
5. **แผนการลงทุน 3 ระดับ** — ตามระดับความรู้และความเสี่ยง
6. **สิ่งที่ควรหลีกเลี่ยง** — เฉพาะชาร์ตนั้น พร้อมเหตุผล
7. **Timing** — ช่วงเวลาที่ควรระวังและเหมาะสม
8. **ขั้นตอนที่ทำได้เลย** — 5 ข้อ เรียงตามลำดับความสำคัญ

### หลักการสำคัญ
- **ห้ามทำนายผลตอบแทน** หรือบอกว่าหุ้นตัวไหนจะขึ้น
- **ห้ามแนะนำสินทรัพย์เฉพาะ** — แนะนำได้แค่ประเภท (Index Fund, หุ้น, อสังหาฯ)
- ต้องมี disclaimer ทุกหน้า
- เน้น **พฤติกรรม** ที่ดวงบ่งบอก ไม่ใช่โชค
- ต้องบอก **กฎ 24 ชม.** สำหรับทุกการตัดสินใจทางการเงิน
