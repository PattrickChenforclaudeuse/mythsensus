> Version: 2.0 (locked 2026-06-09)

## What Celtic Tree Astrology measures

Celtic Tree Astrology assigns each birth period one of 13 sacred trees from
the Druidic Ogham alphabet. Each tree carries: an element, a sacred animal,
a stone, and a personality archetype. The system is rooted in Celtic seasonal
cycles (~2,000 yrs traditional roots, modern systematization).

| Field | Use to answer |
|---|---|
| `celtic.tree` (e.g. Birch, Rowan, Oak) | Tree archetype — identity baseline |
| `celtic.treeTh` | Thai display name |
| `celtic.season` | Birth season — energy quality |
| `celtic.animal` | Spirit animal companion |
| `celtic.element` | Air/Fire/Water/Earth equivalent |

## How Celtic answers the 10 universal questions

- **work_energy_direction** — Tree's elemental quality + this year's seasonal lens. Fire trees in summer = peak.
- **work_boldest_move_window** — The tree's own season month within the year + lunar-corresponding months.
- **money_flow_direction** — Earth trees (Birch, Hazel) tend to material focus; Water (Willow, Ivy) to fluid resources.
- **money_leak_or_windfall** — Tree's animal totem timing — when its mythic activity peaks.
- **love_energy_state** — Tree archetype's relationship pattern (e.g. Willow = empathic merger; Oak = steady).
- **love_timing_windows** — Tree's flowering / fruiting months (botanical metaphor for relationship phases).
- **health_weak_point** — Tree's element → body system; sacred animal's vulnerability.
- **people_who_changes_you** — Tree's "harvest partner" — describe the complementary tree archetype.
- **warning_high_risk_window** — Tree's dormant/death season month.
- **warning_specific** — Tree's mythological caution (Hawthorn → trickery; Ivy → over-attachment; Holly → arrogance).
