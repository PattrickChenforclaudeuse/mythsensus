# Ogham Alphabet Add-on — Framework

> v2.0 · 2026-06-09

## What it measures
Ogham (~1,700 yrs Old Irish) — 20-letter alphabet where each letter is a sacred
tree, used by Druids for divination and lunar calendar. Closely tied to Celtic
Tree but separately encoded — Ogham assigns letter-to-tree explicitly.

| Field | Use |
|---|---|
| `ogham.letter` | Birth Ogham letter |
| `ogham.tree` | Associated tree |
| `ogham.season` | Sacred season |
| `ogham.virtue` | Druidic virtue this letter teaches |
| `months[]` | |

## Q→Hint
- **work_energy_direction** — Letter's virtue alignment with this year's broader cycle.
- **work_boldest_move_window** — Letter's tree-flowering season month.
- **money_flow_direction** — Tree's material yield (fruit-bearer vs sentinel).
- **money_leak_or_windfall** — Letter's "shadow" month per druidic cycle.
- **love_energy_state** — Tree's relationship pattern. Adjust per status.
- **love_timing_windows** — Tree's spring + harvest months.
- **health_weak_point** — Letter's body/elemental affinity.
- **people_who_changes_you** — Companion tree of the Ogham (Druids paired trees).
- **warning_high_risk_window** — Tree's dormant season.
- **warning_specific** — Letter's mythic warning (e.g. Quert/Apple → temptation; Coll/Hazel → over-knowing).
