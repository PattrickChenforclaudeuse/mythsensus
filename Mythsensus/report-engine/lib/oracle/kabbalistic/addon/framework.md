# Kabbalistic Numerology Add-on — Framework

> v2.0 · 2026-06-09

## What it measures
Kabbalistic numerology rooted in Hebrew letters + Tree of Life (~2,500 yrs).
Each Hebrew letter has number value + tarot correspondence + path on the
Tree connecting two sephiroth. Birth date + name yields a birth-path on the
Tree.

| Field | Use |
|---|---|
| `kabbalistic.path` (1-32) | Tree-of-Life birth-path |
| `kabbalistic.sephira` (Keter/Chokmah/.../Malkuth) | Primary sephira |
| `kabbalistic.hebrewLetter` | Letter archetype |
| `kabbalistic.elementCorrespondence` | Fire/Water/Air/Earth |
| `months[]` | |

## 10 Sephiroth (top→bottom)
Keter (crown) → Chokmah (wisdom) → Binah (understanding) → Chesed (mercy)
→ Geburah (severity) → Tiferet (beauty) → Netzach (victory) → Hod (splendor)
→ Yesod (foundation) → Malkuth (kingdom).

## Q→Hint
- **work_energy_direction** — Sephira's life-arc level (upper = abstract; lower = material).
- **work_boldest_move_window** — Months ruled by sephira's path-planet.
- **money_flow_direction** — Lower-Tree sephiroth (Netzach, Hod, Yesod, Malkuth) = material flow.
- **money_leak_or_windfall** — Geburah-pillar months = constraint; Chesed-pillar = expansion.
- **love_energy_state** — Netzach (Venus) + Yesod (foundation) emphasis.
- **love_timing_windows** — Venus-ruled letter months.
- **health_weak_point** — Sephira's body correspondence.
- **people_who_changes_you** — Path companions to one's sephira.
- **warning_high_risk_window** — Geburah-pillar transit months.
- **warning_specific** — Pillar imbalance — too-much-Chesed = over-giving; too-much-Geburah = harshness.
