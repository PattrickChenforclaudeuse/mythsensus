# Ifá / Yoruba Divination Add-on — Framework

> v2.0 · 2026-06-09

## What it measures
Ifá (UNESCO-protected sacred divination; ~10,000 yrs Yoruba tradition) — uses
256 odù (cosmic verses) each carrying ese (parable/teaching). Birth odù
encodes life path + ancestral compact.

| Field | Use |
|---|---|
| `ifaYoruba.odu` | One of 256 odù |
| `ifaYoruba.oduTh` | Thai phonetic |
| `ifaYoruba.oduTheme` | 1-line core teaching |
| `ifaYoruba.orisha` | Patron orisha (deity) |
| `ifaYoruba.taboo` (eewò) | Personal taboo from Ifá |
| `months[]` | |

## Major Orisha (1-line)
Olódùmarè (Supreme), Olorun (sky-source), Orunmila (wisdom of Ifá),
Eshu (gateway, trickster — accompanies all), Ogun (iron/labor),
Yemoja (mother, oceans), Oshun (river/love/wealth), Shango (thunder/justice),
Obatala (creativity/peace), Oya (storm/transformation), Ifá orisha itself.

## Q→Hint
- **work_energy_direction** — Patron orisha's domain.
- **work_boldest_move_window** — Orisha's sacred day month.
- **money_flow_direction** — Oshun (wealth) presence in chart.
- **money_leak_or_windfall** — Eewò (taboo) violations dictate leak source.
- **love_energy_state** — Oshun + Yemoja emphasis. Adjust per status.
- **love_timing_windows** — Orisha festival months.
- **health_weak_point** — Eewò body-correspondence.
- **people_who_changes_you** — Orisha messenger archetype.
- **warning_high_risk_window** — Eshu-activation months (crossroads moments).
- **warning_specific** — Personal eewò: e.g. "avoid red foods" / "don't sit with back to door" — depends on odù.
