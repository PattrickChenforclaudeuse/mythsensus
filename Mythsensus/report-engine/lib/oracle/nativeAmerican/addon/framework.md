# Native American Totem Add-on — Framework

> v2.0 · 2026-06-09

## What it measures
Native American Medicine Wheel astrology — 12 animal totems aligned with
solar cycles. Each totem = elemental + clan + plant + stone correspondences.

| Field | Use |
|---|---|
| `nativeAmerican.totem` | Birth totem animal |
| `nativeAmerican.totemTh` | Thai display |
| `nativeAmerican.clan` (Hawk/Beaver/Deer/Salmon) | Elemental clan |
| `nativeAmerican.season` | Birth season + direction |
| `nativeAmerican.plant` / `stone` | Companion correspondences |
| `months[]` | |

## 12 totems
Otter (Jan 20–Feb 18), Wolf (Feb 19–Mar 20), Falcon (Mar 21–Apr 19),
Beaver (Apr 20–May 20), Deer (May 21–Jun 20), Woodpecker (Jun 21–Jul 21),
Salmon (Jul 22–Aug 21), Brown Bear (Aug 22–Sep 21), Crow / Raven (Sep 22–Oct 22),
Snake (Oct 23–Nov 22), Owl (Nov 23–Dec 21), Snow Goose (Dec 22–Jan 19).

## Q→Hint
- **work_energy_direction** — Totem's hunting/migration pattern + clan element.
- **work_boldest_move_window** — Totem's active-season month.
- **money_flow_direction** — Clan element (Bear/Beaver = builders = inflow).
- **money_leak_or_windfall** — Predator/prey cycle months.
- **love_energy_state** — Totem's mating pattern. Adjust per status.
- **love_timing_windows** — Migration/return seasons.
- **health_weak_point** — Animal's natural vulnerabilities.
- **people_who_changes_you** — Companion totem (pair partner).
- **warning_high_risk_window** — Hibernation/dormant months.
- **warning_specific** — Totem-specific shadow (Owl → over-thinking; Wolf → loneliness).
