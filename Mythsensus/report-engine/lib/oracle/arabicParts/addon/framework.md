# Arabic Parts (Lots) Add-on — Framework

> v2.0 · 2026-06-09

## What it measures
Arabic Parts (Lots / السهام) — Hellenistic-Persian-Arabic computed sensitive
points (~1,500 yrs). Each Lot = a formulaic combination of Asc + 2 planet
positions. The **Lot of Fortune** (Asc + Moon - Sun) and **Lot of Spirit**
(Asc + Sun - Moon) are the two most-studied.

| Field | Use |
|---|---|
| `arabicParts.lotFortune` (sign + degree) | Material destiny |
| `arabicParts.lotSpirit` | Vocational/spiritual destiny |
| `arabicParts.lotEros` | Love lot |
| `arabicParts.lotNecessity` | Constraints / karma |
| `months[]` | |

## Q→Hint
- **work_energy_direction** — Lot of Spirit's domicile lord this year.
- **work_boldest_move_window** — When Lot of Spirit gets transited by benefic.
- **money_flow_direction** — Lot of Fortune's house location + lord.
- **money_leak_or_windfall** — Malefic transit through Lot of Fortune's degree.
- **love_energy_state** — Lot of Eros + Lot of Marriage when computed.
- **love_timing_windows** — Venus transit to Lot of Eros.
- **health_weak_point** — Lot of Necessity's house emphasis.
- **people_who_changes_you** — Lord of Lot of Spirit.
- **warning_high_risk_window** — Lot of Necessity activation month.
- **warning_specific** — Specific to the malefic transiting key Lots.
