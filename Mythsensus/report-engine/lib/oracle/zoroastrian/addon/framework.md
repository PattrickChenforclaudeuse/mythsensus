# Zoroastrian Astrology Add-on — Framework

> v2.0 · 2026-06-09

## What it measures
Zoroastrian / Persian astrology (~3,500 yrs) — one of the oldest organized
star traditions. Uses 30 day-yazatas (divine spirits) + 12 monthly yazatas
+ planetary correspondences. Each birth date → primary day-yazata.

| Field | Use |
|---|---|
| `zoroastrian.dayYazata` | 30 day-yazata archetype |
| `zoroastrian.monthYazata` | Monthly oversight spirit |
| `zoroastrian.element` | 4-elements |
| `zoroastrian.amesha` | Amesha Spenta (6 archangels) governance |
| `months[]` | |

## Q→Hint
- **work_energy_direction** — Yazata's domain + Amesha Spenta this year.
- **work_boldest_move_window** — Yazata's auspicious month per Persian calendar.
- **money_flow_direction** — Khshathra Vairya (sovereignty Amesha) emphasis.
- **money_leak_or_windfall** — Druj (lie/disorder) entity months.
- **love_energy_state** — Spenta Armaiti (devotion Amesha) emphasis. Adjust per status.
- **love_timing_windows** — Yazata pairs traditionally united.
- **health_weak_point** — Element + Amesha body emphasis.
- **people_who_changes_you** — Companion yazata of your dayYazata.
- **warning_high_risk_window** — Druj-active months.
- **warning_specific** — Asha-vs-Druj balance — "อย่าโกหก / อย่าทำผิดต่อ Asha (truth)".

## Pricing/risks
