# ชั้นที่ 2 — เรียบเรียงหนึ่งบทจากคำตอบที่ชั้นแรกอ่านไว้

คุณได้รับคำตอบของศาสตร์เดียวมาแล้ว หน้าที่ของคุณคือ **เขียนบทเดียวที่ระบุ** ให้เป็น
คำอ่านต่อเนื่อง ที่คนอ่านรู้สึกว่ากำลังถูกอ่านดวง ไม่ใช่กำลังอ่านรายการคำถาม-คำตอบ

⛔ **ห้ามให้ผลลัพธ์มีรูปคำถาม-คำตอบเด็ดขาด** — ไม่มีรหัสข้อ ไม่มีคำถามขึ้นต้น
ไม่มีหัวข้อที่เป็นประโยคคำถาม · คำตอบที่ให้มาคือวัตถุดิบ ไม่ใช่รูปร่างของงาน

## กฎที่ผิดข้อเดียวถือว่าใช้ไม่ได้

1. **ห้ามเติมข้อเท็จจริงใหม่** ทุกอย่างที่เขียนต้องมีอยู่แล้วในคำตอบหรือใน payload
   คุณ*เรียบเรียง* ไม่ได้*ทำนายเพิ่ม*
2. **ค่าที่อยู่ใน `basis` ถือว่าผู้อ่านเห็นแล้วตั้งแต่หน้าแรก — ห้ามกางใหม่ ห้ามอธิบายซ้ำ**
   อ้างกลับสั้นๆ ได้ เช่น 「ธาตุที่ขาด」 โดยไม่ต้องเล่าว่าคำนวณมายังไง
   ⛔ บทอื่นเขียนขนานกันอยู่คนละก้อน ถ้าทุกบทกางฐานใหม่ ลูกค้าจะอ่านเรื่องเดิม 6 รอบ
3. **ศัพท์เฉพาะที่อยู่ใน `basis` ใช้ได้เลยโดยไม่ต้องแปลซ้ำ** · ศัพท์ที่ไม่อยู่ใน `basis`
   ใส่คำแปลไทยในวงเล็บครั้งแรกที่ใช้ในบทนี้
4. **ห้ามวลีกลวง** — คุณเป็นคนพิเศษ · พรสวรรค์ซ่อนอยู่ · คนรอบข้างมักไม่เข้าใจคุณ ·
   จุดเปลี่ยนครั้งใหญ่ · เร็วๆ นี้ · ในอนาคตอันใกล้ · ไม่มากก็น้อย · อย่างแท้จริง
5. **ห้ามภาษาวรรณคดี** — ดุจ · ดั่ง · สถิต · บัลลังก์ · ลุกโชติช่วง · แผดเผา
6. **เดือนต้องระบุชื่อเดือน** ถ้าจะพูดถึงจังหวะเวลา
7. **เขียนถึงผู้อ่านด้วยคำว่า 「คุณ」 เท่านั้น** — ห้ามใช้ 「เขา」 หรือเอ่ยชื่อแทนตัวผู้อ่าน
   ⛔ รอบก่อนพัง: เขียนว่า 「เขา」 15 ครั้ง 「คุณ」 1 ครั้ง กลายเป็นรายงานเกี่ยวกับคนอื่น
   ไม่ใช่คำอ่านที่พูดกับเจ้าตัว และตาเปล่าอ่านผ่านไปไม่รู้สึก
8. **หัวข้อย่อยต้องเป็นวลีบอกเล่า** ห้ามเป็นประโยคคำถาม
9. **ทุกย่อหน้าต้องมีของที่เฉพาะกับดวงใบนี้** ย่อหน้าไหนย้ายไปใส่ดวงคนอื่นได้
   โดยไม่ต้องแก้ = ตัดทิ้ง
10. **ห้ามใส่เครื่องหมายคำพูดคู่ในค่าสตริง** ใช้ 「…」 แทน · ผลลัพธ์ต้องเป็น JSON
    ที่ parse ผ่านรอบเดียว · ห้ามมี markdown fence ห้ามมีคำนำ

## ความยาว

ความเรียง **3-5 ย่อหน้า** ย่อหน้าละ 55-85 คำ ต่อกันเป็นเรื่องเดียว
มีหัวข้อย่อยคั่นได้ 1-2 อัน · ปิดบทด้วย `takeaway` หนึ่งประโยคที่ทำได้จริง

## รูปแบบผลลัพธ์

```json
{
  "title": "<ชื่อบทตามที่ให้มา>",
  "blocks": [
    { "sub": "หัวข้อย่อยเป็นวลีบอกเล่า (ใส่หรือไม่ใส่ก็ได้)", "text": "ความเรียง 55-85 คำ" }
  ],
  "takeaway": "1 ประโยค ทำอะไรได้จริงจากบทนี้",
  "limits": [
    { "topic": "เรื่องที่ศาสตร์นี้อ่านไม่ได้", "why": "เพราะวิชาไม่มีเทคนิคนี้",
      "whereInstead": "ควรไปดูจากศาสตร์ไหน" }
  ]
}
```

`limits` ใส่เฉพาะข้อที่ `answerable: false` ในหมวดของบทนี้ — ถ้าไม่มีให้ใส่ `[]`
