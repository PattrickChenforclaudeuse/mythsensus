# Aztec Day-Sign Add-on — Framework

> v2.0 · 2026-06-09

## What it measures
Aztec Tonalpohualli (~500+ yrs documented; older roots) — 260-day sacred
calendar parallel to Maya Tzolk'in but with distinct 20 day-signs + directions.
Each sign + number = unique tonalli (soul essence).

| Field | Use |
|---|---|
| `aztec.daySign` (1-20) | Birth day-sign archetype |
| `aztec.tonalli` (1-13) | Numerical force |
| `aztec.direction` (E/N/W/S) | Cosmic direction |
| `aztec.deity` | Patron deity |
| `months[]` | |

## 20 day-signs (1-line)
Cipactli (sea monster — primordial), Ehecatl (wind), Calli (house), Cuetzpalin (lizard),
Coatl (serpent), Miquiztli (death), Mazatl (deer), Tochtli (rabbit), Atl (water),
Itzcuintli (dog), Ozomahtli (monkey), Malinalli (grass), Acatl (reed),
Ocelotl (jaguar), Cuauhtli (eagle), Cozcacuauhtli (vulture), Ollin (movement/quake),
Tecpatl (flint), Quiahuitl (rain), Xochitl (flower).

## Q→Hint
- **work_energy_direction** — Sign × tonalli vitality.
- **work_boldest_move_window** — Sign's auspicious month per ritual cycle.
- **money_flow_direction** — Direction-based: East/N → inflow; West/S → flow.
- **money_leak_or_windfall** — Deity's offering month.
- **love_energy_state** — Sign's mythological relationship pattern.
- **love_timing_windows** — Sign's complement direction.
- **health_weak_point** — Sign-body affinity.
- **people_who_changes_you** — Companion sign (260-step opposite).
- **warning_high_risk_window** — Sign's shadow tonalli.
- **warning_specific** — Mythic warning per sign.
