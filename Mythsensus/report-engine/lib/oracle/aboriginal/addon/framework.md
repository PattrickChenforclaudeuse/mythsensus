# Aboriginal Dreaming Add-on — Framework

> v2.0 · 2026-06-09

## What it measures
Aboriginal Dreaming (~65,000 yrs, the world's oldest continuous knowledge system).
The Dreaming is the time-out-of-time when ancestor spirits formed land, animals,
and people. Each birth corresponds to a Dreaming Ancestor + clan + totem +
land-songline.

| Field | Use |
|---|---|
| `aboriginal.dreamingAncestor` | Primary Dreaming Ancestor |
| `aboriginal.dreamingTh` | Thai display |
| `aboriginal.season` | One of 6 Aboriginal seasons |
| `aboriginal.totem` | Animal totem |
| `aboriginal.songline` (when available) | Land-pathway songline |
| `months[]` | |

## Q→Hint
- **work_energy_direction** — Ancestor's element + season alignment.
- **work_boldest_move_window** — Songline-festival month.
- **money_flow_direction** — Ancestor's gift archetype (creator/keeper/teacher).
- **money_leak_or_windfall** — Disconnect-from-totem months.
- **love_energy_state** — Totem's mating + community pattern.
- **love_timing_windows** — Seasonal partnership cycles.
- **health_weak_point** — Totem's vulnerabilities.
- **people_who_changes_you** — Companion ancestor in same songline.
- **warning_high_risk_window** — Dry/fire season for water-totems; wet season for fire-totems.
- **warning_specific** — Respect-totem warnings (e.g. "don't eat your totem").
