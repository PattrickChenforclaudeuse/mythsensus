คุย Claude / ChatGPT เรื่องดวงคุณเอง

ติดตั้งครั้งเดียว ถาม AI เรื่องอนาคต ความรัก งาน การตัดสินใจ — AI จะอ้างอิงรายงาน 26 ศาสตร์ของคุณเสมอ

1
เปิดไฟล์ config ของ Claude Desktop
ถ้ายังไม่มี Claude Desktop ดาวน์โหลดฟรีที่ claude.ai/download
ตำแหน่งไฟล์ config:
• macOS ~/Library/Application Support/Claude/claude_desktop_config.json
• Windows %APPDATA%\Claude\claude_desktop_config.json
• Linux ~/.config/Claude/claude_desktop_config.json
2
วาง config นี้ลงไป
ใส่แทนทั้งไฟล์ (หรือรวมกับ mcpServers ที่มีอยู่):
{
  "mcpServers": {
    "mythsensus": {
      "command": "npx",
      "args": ["-y", "mythsensus-mcp"]
    }
  }
}
หมายเหตุ: ต้องติดตั้ง Node.js 18+ ก่อน เช็คด้วย node --version — ถ้ายังไม่มี nodejs.org
3
ปิดแล้วเปิด Claude Desktop ใหม่
พอ Claude เปิดใหม่ จะเห็น icon 🔌 tools — กดดูว่ามี Mythsensus ขึ้นหรือยัง แล้วถามอะไรเกี่ยวกับดวงได้เลย

🛠 BUILD ด้วย MYTHSENSUS

ฝัง engine 26 ศาสตร์ ลง app ของคุณ

MCP server แบบ open-source · deterministic — วันเกิดเดียวกันได้ Cosmic Score เหมือนเดิมทุกครั้ง · MIT license · เอาไปทำ horoscope chatbot, daily blessing, astrology API หรืออะไรที่ AI ต้องรู้จักผู้ใช้

ติดตั้ง
# Use directly via npx (recommended for MCP clients)
npx -y mythsensus-mcp

# Or install globally
npm install -g mythsensus-mcp

# Or as a dependency in your project
npm install mythsensus-mcp
Tools ที่ใช้ได้
calculate_cosmic_score(year, month, day, [hour, lat, lon, tz])
คำนวณ Cosmic Score 1–1,000 จากวันเกิด · คืน score + tier (Common → Mythic) + percentile + breakdown 26 ศาสตร์ · deterministic
get_deep_reading(chart, system)
คำอ่านลึก 500–800 คำของ 1 ศาสตร์: bazi, vedic, western, ninestar, numerology, thai_seven_number, mayan_tzolkin, norse_runes, human_design และอีก 17 ศาสตร์ · เลือกภาษา en/th
draw_daily_blessing(date, chart_hash)
ดึงเทพประจำวันจากคลัง 1,069 องค์ (Common → Mythic) · คืนชื่อเทพ + ตำนาน + ข้อความพรประจำวัน · deterministic ตาม chart + date
ask_108_organum(question, chart)
ถามคำถาม · เลือกเทพ 108 องค์ (bias ตามหัวข้อ: ความรัก → Lakshmi/Aphrodite, เงิน → Caishen/Hermes ฯลฯ) · แต่ละองค์ลงคะแนน · คำที่ consensus = คำตอบ · deterministic
list_26_systems()
คืน metadata 26 ศาสตร์: ชื่อ + ชื่ออังกฤษ + ภูมิภาคต้นกำเนิด + ฟิลด์ที่ต้องใช้ + คำอธิบาย 1 บรรทัด · ใช้ดูว่าทำอะไรได้บ้าง
Use cases
  • Horoscope chatbot — บอท Discord / Telegram ส่งคำทำนายประจำวันให้สมาชิก
  • แอป spiritual coaching — ฝัง deep reading ลงในแอป wellness หรือ therapy
  • Astrology API สำหรับสำนักข่าว — gen คอลัมน์ดูดวงประจำวันจาก chart จริง
  • แอป dating — คำนวณ compatibility จาก BaZi + Western + Vedic ในการเรียก 1 ครั้ง
  • Show HN / portfolio demo — MCP server ในวงการดูดวงที่ดาวเยอะที่สุด (เป็นเจ้าแรก)
