## ต้นเหตุ — `src/engine/calc.cjs` บรรทัด 145-158

```js
function ascLongitude(jd, hour, lat, lon) {
    const D = jd - 2451545.0;
    const GMST = mod360(280.46061837 + 360.98564736629 * D);
    const LST  = mod360(GMST + lon);
    const RAMC = toRad(mod360(LST + hour * 15));          // ← บั๊ก 1
    ...
    let asc = toDeg(Math.atan2(Math.cos(RAMC), -(...)));
    if (Math.cos(RAMC) < 0) asc += 180;                    // ← บั๊ก 2
    return mod360(asc);
}
```

**บั๊ก 1 — นับเวลาซ้ำสองรอบ.** `jd` ที่ส่งเข้ามาถูกสร้างจาก `toJD(y,m,d,utcHour)` คือ
**รวมเวลาไปแล้ว** → `GMST` เดินตามเวลาแล้ว (~15.04°/ชม.) แต่โค้ดบวก `hour*15` เข้าไปอีก
= เวลาถูกนับ **~30°/ชม.** → ลัคนาหมุนครบ 2 รอบต่อวันแทนที่จะเป็น 1 รอบ
(ตรงกับที่วัดได้ว่ารอบซ้ำทุก 12 ชม. พอดี)

**บั๊ก 2 — แก้ quadrant เกิน.** `atan2` คืนค่า quadrant ถูกอยู่แล้ว การบวก 180 เพิ่ม
เมื่อ `cos(RAMC)<0` ทำให้พลิกผิด → เคส London 2000-01-01 ออกมาห่างจากค่าจริงพอดี 180°
