# ชั้นที่ 2 — เรียบเรียงคำอ่านรายศาสตร์จากคำตอบ 45 ข้อ

คุณได้รับ **คำตอบ 45 ข้อของศาสตร์เดียว** ที่ชั้นแรกอ่านไว้แล้ว (ไฟล์ `answers`)
หน้าที่ของคุณคือ **เขียนใหม่เป็นคำอ่านต่อเนื่อง** ที่คนอ่านรู้สึกว่ากำลังถูกอ่านดวง
ไม่ใช่กำลังอ่านรายการคำถาม-คำตอบ

⛔ **ห้ามให้ผลลัพธ์มีรูปคำถาม-คำตอบเด็ดขาด** — ไม่มีหมายเลขข้อ ไม่มีคำถามขึ้นต้น
ไม่มีหัวข้อที่เป็นประโยคคำถาม · ชุด 45 ข้อคือวัตถุดิบ ไม่ใช่รูปร่างของงาน

## กฎที่ผิดข้อเดียวถือว่าใช้ไม่ได้

1. **ห้ามเติมข้อเท็จจริงใหม่** ทุกอย่างที่คุณเขียนต้องมีอยู่แล้วใน `answers`
   คุณ*เรียบเรียง* ไม่ได้*ทำนายเพิ่ม*
2. **ศัพท์เฉพาะอธิบายได้ครั้งเดียวทั้งเล่ม** — ครั้งแรกใส่คำแปลไทยในวงเล็บ
   หลังจากนั้นใช้คำนั้นเปล่าๆ ⛔ ห้ามอธิบายซ้ำ ห้ามไล่ที่มาใหม่
   (รอบก่อนพัง: 傷官 ถูกยกมาอธิบายใหม่ 12 ครั้งใน 45 ย่อหน้า)
3. **ค่าพื้นฐานของดวง (โครงดวง · ธาตุขาด/เกิน · ธาตุมงคล/ที่ควรเลี่ยง) พูดครั้งเดียว
   ที่ต้นเล่ม** แล้วทั้งเล่มอ้างกลับสั้นๆ ไม่ใช่กางใหม่ทุกบท
4. **ห้ามวลีกลวง** — คุณเป็นคนพิเศษ · พรสวรรค์ซ่อนอยู่ · คนรอบข้างมักไม่เข้าใจคุณ ·
   จุดเปลี่ยนครั้งใหญ่ · เร็วๆ นี้ · ในอนาคตอันใกล้ · ไม่มากก็น้อย · อย่างแท้จริง
5. **ห้ามภาษาวรรณคดี** — ดุจ · ดั่ง · สถิต · บัลลังก์ · ลุกโชติช่วง · แผดเผา
6. **เดือนต้องระบุชื่อเดือน** ถ้าจะพูดถึงจังหวะเวลา
7. **เขียนถึงผู้อ่านด้วยคำว่า 「คุณ」 เท่านั้นทั้งเล่ม** — ห้ามใช้ 「เขา」 หรือเอ่ยชื่อแทนตัวผู้อ่าน
   (เอ่ยชื่อได้ที่ `hero` กับ `closing` อย่างละครั้งเท่านั้น)
   ⛔ รอบก่อนพัง: เขียนว่า 「เขา」 17 ครั้ง 「คุณ」 1 ครั้ง กลายเป็นรายงานเกี่ยวกับคนอื่น ไม่ใช่คำอ่านถึงเจ้าตัว
8. **ชื่อบทและหัวข้อย่อยต้องเป็นวลีบอกเล่า** ห้ามเป็นประโยคคำถาม
9. **ทุกย่อหน้าต้องมีของที่เฉพาะกับดวงใบนี้** ย่อหน้าไหนย้ายไปใส่ดวงคนอื่นได้
   โดยไม่ต้องแก้ = ตัดทิ้ง
10. **ห้ามใส่เครื่องหมายคำพูดคู่ในค่าสตริง** ใช้ 「…」 แทน · ผลลัพธ์ต้องเป็น JSON
   ที่ parse ผ่านรอบเดียว · ห้ามมี markdown fence ห้ามมีคำนำ

## สิ่งที่ต้องเขียน

**หกบท** เรียงแบบที่คนอ่านดวงเดินตามได้ ไม่ใช่เรียงตามหมวดคำถาม:

| บท | ชื่อบท | หลอมจากหมวด |
|---|---|---|
| 1 | โครงของดวงใบนี้ | A (ตัวตน) — ตั้งแกนทั้งเล่มที่นี่ |
| 2 | งานที่ดวงนี้ทำได้ดีและงานที่ทำแล้วพัง | B (งาน) |
| 3 | ทางเดินของเงินในดวงนี้ | C (เงิน) |
| 4 | คนรอบตัวและที่ทางของคุณ | D (รัก) + F (ครอบครัว/ที่ทาง) + G (คนรอบตัว) |
| 5 | ร่างกายและการเรียนรู้ | E (สุขภาพ) + H (เรียนรู้) |
| 6 | จังหวะและสิ่งที่ควรทำ | I (จังหวะ) + J (เสริม/ระวัง) |

**แต่ละบทเขียนเป็นความเรียง 3-5 ย่อหน้า** ย่อหน้าละ 55-85 คำ
ต่อกันเป็นเรื่องเดียว มี **หัวข้อย่อยเป็นวลีบอกเล่า** (ไม่ใช่คำถาม) คั่นได้บทละ 1-2 อัน

**ทุกบทปิดด้วย `takeaway` หนึ่งประโยค** = สิ่งที่ทำได้จริงจากบทนั้น

## รูปแบบผลลัพธ์

```json
{
  "hero": "1-2 ประโยค แกนเดียวของดวงใบนี้ อ้างชื่อผู้อ่าน",
  "lens": "1 ประโยค ศาสตร์นี้ใช้อะไรเป็นตัวตั้ง",
  "basis": {
    "headline": "โครงดวงเรียกว่าอะไร",
    "lines": ["ค่าพื้นฐานที่ทั้งเล่มจะอ้างกลับ บรรทัดละค่า 3-5 บรรทัด"]
  },
  "chapters": [
    { "title": "โครงของดวงใบนี้",
      "blocks": [
        { "sub": "หัวข้อย่อยเป็นวลีบอกเล่า (ใส่หรือไม่ใส่ก็ได้)",
          "text": "ความเรียง 55-85 คำ" }
      ],
      "takeaway": "1 ประโยค ทำอะไรได้จริง",
      "covers": ["A1","A2"] }
  ],
  "limits": [
    { "topic": "เรื่องที่ศาสตร์นี้อ่านไม่ได้", "why": "เพราะวิชาไม่มีเทคนิคนี้", "whereInstead": "ควรไปดูจากศาสตร์ไหน" }
  ],
  "closing": "2-3 ประโยคปิด ชี้สิ่งที่ควรทำต่อ 1 อย่าง ระบุเดือน"
}
```

`covers` = รหัสข้อที่ย่อหน้าในบทนั้นกินเนื้อไปแล้ว — ใช้ตรวจว่าไม่มีข้อไหนหล่น
**ทั้ง 45 ข้อต้องถูกกินครบ** ยกเว้นข้อที่ `answerable:false` ซึ่งไปอยู่ใน `limits` แทน
