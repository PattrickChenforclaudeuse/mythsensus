How It Works · ทำงานยังไง

Engine คำนวณใน browser ของคุณ ไม่ส่งข้อมูลออก

วันเกิดของคุณเป็นเรื่องส่วนตัว Mythsensus จึงออกแบบให้การคำนวณดวง 26 ศาสตร์ทำใน browser ของคุณเอง — ไม่ส่งวันเกิดไป server ใด ๆ. หน้านี้อธิบาย architecture + วิธีพิสูจน์ด้วยตัวเองใน 30 วินาที

✦ สรุปสั้น ๆ ๔ ข้อ
  • Engine ทำงานในเบราว์เซอร์ของคุณ ไม่มีการเรียก API ไม่ส่งวันเกิดออกจากเครื่อง · พิสูจน์ได้ผ่าน DevTools ภายใน ๓๐ วินาที
  • ตัวเลขและคะแนนทุกตัวคำนวณแบบกำหนดผล (deterministic) ไม่มี LLM อยู่ในเส้นทางคำนวณ · เนื้อหาเชิงเล่าเรื่องเป็นส่วนที่ AI ช่วยร่างจากคัมภีร์ดั้งเดิมที่อ้างอิงได้ · ดูจุดแบ่งให้ชัด →
  • การลงชื่อเข้าใช้เป็นทางเลือก เก็บแค่อีเมลและสถานะการสมัครเท่านั้น ไม่เก็บวันเกิดหรือเนื้อหาในแผนภูมิดวง
  • เปิดข้อจำกัดทุกข้อ ไม่ปกปิด — engine v1 มีจุดที่ยังคำนวณไม่สมบูรณ์เล็กน้อย (เช่น คนเกิดก่อนปี ๑๙๐๐ บางวัน ตำแหน่งดาวอาจคลาดเคลื่อนนิดหน่อย). ทุกจุดเปิดในตาราง "ข้อจำกัดที่เรารู้" ด้านล่าง พร้อมวันที่จะแก้
⚖️ เส้นแบ่งระหว่างการคำนวณกับ AI

คะแนนเป็นการคำนวณ ไม่ใช่ AI — Cosmic Score และคะแนนทั้ง 26 ศาสตร์ เราคำนวณด้วยสูตรดาราศาสตร์มาตรฐานและตารางอ้างอิงดั้งเดิมของแต่ละศาสตร์ ไม่มี AI อยู่ในเส้นทางการคำนวณ. วันเกิดของคุณให้คะแนนเดียวกันเสมอ — ไม่ว่าเปิดอ่านวันไหน อยู่ที่ไหนในโลก ตรวจสอบซ้ำได้

เนื้อหาเล่าเรื่อง AI ช่วยเขียน — แต่เขียนจากคัมภีร์ดั้งเดิม — เรื่องเล่าเทพ คำอธิบายความหมาย คำแนะนำการปฏิบัติ AI เรียบเรียงให้ แต่อิงจากตำราของแต่ละศาสตร์เอง: ตำราพระเวท คัมภีร์ BaZi ปฏิทินมายันต้นฉบับ ฯลฯ AI ไม่ได้แต่งเรื่องใหม่ — แค่แปลตำราเก่าให้อ่านง่าย

Flow · เกิดอะไรขึ้นเมื่อคุณใช้

1. First visit · ครั้งแรกที่เข้า

Browser ของคุณ download static files จาก Vercel CDN: HTML (~1.3 MB), JS engine bundle (~250 KB), gods.json (~700 KB), fonts. นี่เป็น HTTP requests มาตรฐาน ปกติของเว็บทั่วไป — เหมือนเปิด Wikipedia

2. App caches itself · App เก็บตัวเองในเครื่อง

Service worker (browser feature) cache ทุกอย่างไว้ในเครื่องคุณ ครั้งต่อไปคุณเปิดเว็บ — เปิดได้แม้ไม่มีอินเทอร์เน็ต (offline-capable)

3. You enter your birth data · คุณกรอกวันเกิด

คุณใส่วันเกิด (เวลา + เมืองเป็น optional) ในฟอร์ม HTML ของหน้าแรก ข้อมูลอยู่ใน JavaScript variable ของ browser tab — ยังไม่ไปไหน

4. Engine runs locally · คำนวณในเครื่องคุณ

คุณกด Generate — engine เรียก calculate({year, month, day, hour, minute, lat, lon, timezone}) ฟังก์ชันนี้รันใน CPU ของอุปกรณ์คุณเอง คำนวณ 26 ศาสตร์ออกมาเป็น chart object ไม่มี HTTP request ใด ๆ เกิดขึ้นในขั้นตอนนี้

5. Reading renders · รายงานแสดงผล

Chart object ถูก render เป็น HTML ผ่าน generateReport(chart) ที่รันใน browser เช่นกัน คุณเห็น Cosmic Score + 26 ศาสตร์บนหน้าจอ ทั้งหมดยังอยู่ใน browser tab ของคุณ

6. Your data stays on your device · ข้อมูลเก็บในเครื่องคุณ

วันเกิดและ chart ของคุณถูก save ไว้ใน localStorage ของ browser — กล่องเก็บข้อมูลใน hard drive ของอุปกรณ์ ไม่ shared กับเว็บอื่น ไม่ส่งไปที่ server ครั้งหน้าเปิดเว็บ — อ่าน localStorage แล้ว render ทันที

พิสูจน์ด้วยตัวเองใน 30 วินาที

  1. เปิด mythsensus.com ในเบราว์เซอร์
  2. กด F12 (Windows) หรือ Cmd+Option+I (Mac) — เปิด DevTools
  3. ไปที่แท็บ Network ใน DevTools
  4. กด Ctrl+R (หรือ Cmd+R) — reload หน้า. ดู requests ที่เข้ามา (static files download)
  5. ใส่วันเกิดของคุณ → กด Generate
  6. ดู Network tab อีกครั้ง — ไม่มี request ใหม่ไปที่ /api/calculate หรือใด ๆ ที่มีวันเกิดคุณส่งออกไป

นี่คือพิสูจน์ที่ดีที่สุด — browser ของคุณเห็นทุก HTTP request ที่ออกไป ถ้าเราส่งวันเกิดไป server คุณจะเห็นใน Network tab ทันที

"Reconcile" หมายความว่าอะไร · What "reconcile" actually means

คำว่า "reconcile 26 systems" ไม่ได้แปลว่า engine มีผู้พิพากษาภายในที่ตัดสินใจแทนคุณ — มันคือการวัด agreement ระหว่างเสียงของ 26 ศาสตร์ พร้อมเก็บเสียงที่เห็นต่างไว้ให้คุณเห็น 3 ระดับ

ระดับ 1 · Cosmic Score = ระดับดวงโดยรวมของคุณข้าม 26 ศาสตร์

26 ศาสตร์ identity คำนวณ sub-score ของตัวเองจากวันเกิดคุณ · Biorhythm เป็นชั้นรายวัน (ศาสตร์ที่ 27) ที่เปลี่ยนทุกวัน — แสดงแยก ไม่นับใน scoring จึงเหลือ 26 ศาสตร์ · Cosmic Score คือ ระดับดวงโดยรวมของคุณข้ามทั้ง 26 ศาสตร์ map ผ่าน frozen reference distribution เป็น percentile ประชากร 1 ถึง 1,000 (ยิ่งสูง = การอ่านโดยรวมยิ่งเข้มข้น) · ควบคู่กันมี Consensus reading ที่วัดว่า 26 ศาสตร์เห็นตรงกันแค่ไหน — แสดงแยกจากตัวคะแนน:

  • คะแนนสูง = การอ่านโดยรวมของคุณเข้มข้นเมื่อเทียบประชากร — เป็นเปอร์เซ็นไทล์จริงเทียบ reference distribution
  • คะแนนต่ำ = ดวงที่เงียบกว่าหรือหลายมิติ — ไม่ใช่ "โชคไม่ดี" แต่คือซับซ้อน/หลายมิติ (multi-faceted) — เราไม่เคยใส่กรอบว่าต่ำ = แย่
  • Consensus reading (แยกต่างหาก) — วัดว่า 26 ศาสตร์เห็นตรงกันแค่ไหน · เห็นตรงกันสูงในทางสถิติหายาก เพราะแต่ละศาสตร์ใช้กรอบเวลา/ธาตุที่ เข้ากันไม่ได้เลย (BaZi 五行+jiéqì · Vedic sidereal · Western tropical+4-ธาตุ · Mayan Tzolk'in 260 วัน · ปฏิทินจันทรคติไทย ฯลฯ) — agreement ข้ามกรอบพวกนี้ไม่ใช่เรื่องบังเอิญ
  • Percentile จริง — เพราะ map ผ่าน reference distribution ของประชากร ป้ายระดับ "Top X%" จึงเป็นตัวเลขจริง ไม่ใช่การตลาด

ผลคือคะแนนไวต่อเวลาเกิดถึงระดับนาที — เพราะแต่ละศาสตร์คำนวณตำแหน่งของมันเองบนกรอบเวลาของตัวเอง เวลาเกิดขยับ = sub-score ขยับไม่เท่ากันในแต่ละศาสตร์ · นี่คือ astrological fidelity ที่ถูกต้อง ไม่ใช่ bug

ทำไมนี่คือ "การวัด" ไม่ใช่ "judge" — engine ไม่ตัดสิน คุณ แต่วัด ระดับดวงโดยรวมของคุณ (และควบคู่กัน ว่าเสียงของศาสตร์เห็นตรงกันแค่ไหน) โดย map ผ่าน frozen reference distribution ที่ freeze ตั้งแต่ calibration · เหมือนเครื่องวัดที่รายงานตามกติกาที่ประกาศไว้แล้ว — ไม่ใช่ผู้พิพากษาที่ใช้ดุลพินิจส่วนตัว · ดูสูตร calibration + dataset → · ดู calibration methodology ฉบับเต็ม →

เทียบกับเว็บดูดวงทั่วไป

เว็บดูดวงส่วนใหญ่คำนวณบน server ของพวกเขา — คุณส่งวันเกิด, ราคา, อาจจะ email มาให้ server บริการคืน reading. ผลที่ตามมา:

  • ข้อมูล — วันเกิดอยู่ใน database ของพวกเขา รั่วได้ ใช้สำหรับ remarketing ได้
  • การเข้าถึง — ต้องลงทะเบียน + verify email + ต้องมีอินเทอร์เน็ตเสมอ
  • ความสม่ำเสมอ — เปลี่ยน design ครั้งใหม่ คะแนนเปลี่ยนตาม (คำนวณ server-side ใหม่ทุกครั้ง ไม่ pin engine version)

Mythsensus เลือกทางตรงข้าม — คำนวณบนเครื่องคุณ engine deterministic + version-locked วันเกิดเดียวกันให้คะแนนเดียวกัน ทุกที่ ทุกเวลา

คำถามที่พบบ่อย

คำนวณดวงใน browser ของฉันจริง ๆ หรือ?

จริง — engine 26 ศาสตร์ (~250 KB JavaScript) ถูก compile จาก TypeScript และ load เข้า browser ของคุณตอนเปิดเว็บครั้งแรก หลังจากนั้นการคำนวณรันใน CPU/RAM ของอุปกรณ์คุณเอง วันเกิดที่คุณใส่อยู่ใน memory ของ browser tab เท่านั้น ไม่ถูกส่งไปที่ Mythsensus server ใด ๆ ในระหว่างการคำนวณ

วิธีพิสูจน์ว่าไม่ส่งข้อมูลออก?

เปิด DevTools (F12 หรือ Cmd+Option+I) ไปที่แท็บ Network กด Ctrl+R reload หน้า ใส่วันเกิดของคุณ กด Generate — ดูใน Network tab ว่ามี request ไปที่ /api/calculate หรือใด ๆ ที่มีวันเกิดส่งไปหรือไม่ คำตอบ: ไม่มี (ยกเว้น analytics ภายในที่ไม่ส่งวันเกิด)

แล้ว Cosmic Blueprint $19 ส่งข้อมูลออกไหม?

การชำระเงิน $19 ไปที่ Gumroad (merchant of record สำหรับ card processing + tax + receipt) — email และข้อมูล payment ส่งไปที่ Gumroad ไม่ใช่ Mythsensus. การคำนวณรายงาน เชิงลึกยังคงรันใน browser ของคุณเอง ไม่ใช่ server ของเรา — เราเก็บแค่ payment status (active/inactive) ผ่าน Gumroad webhook ไม่เก็บวันเกิดหรือเนื้อหารายงาน

localStorage คืออะไร? ปลอดภัยไหม?

localStorage คือกล่องเก็บข้อมูลใน browser ของคุณเอง — แต่ละ origin (mythsensus.com) มีกล่องของตัวเอง ไม่ shared กับเว็บอื่น และไม่ส่งไปที่ server ใด ๆ ข้อมูลอยู่ใน hard drive ของอุปกรณ์คุณเท่านั้น เคลียร์ browser cache = ข้อมูลหายหมด เพราะ Mythsensus ไม่มี backup บน server (เป็นข้อจำกัดที่จงใจ — privacy-first)

ใช้ผ่าน AI (MCP) ส่งข้อมูลออกไหม?

Mythsensus เปิดให้ AI เรียก engine ผ่าน MCP ได้ 2 ทาง และ 2 ทางนี้ต่างกันตรงจุดนี้พอดี — npx -y mythsensus-mcp (npm) รัน engine ในเครื่องผู้ใช้เอง วันเกิดไม่ออกจากเครื่อง เหมือนตอนใช้เว็บ · แต่ https://mythsensus.com/mcp (hosted) ส่งวันเกิดมาคำนวณที่ server ของเรา แล้วส่งผลกลับ — เราไม่เก็บและไม่ log แต่ข้อมูลออกจากเครื่องจริง ถ้าต้องการให้คำนวณในเครื่องเท่านั้น ให้ใช้ทาง npm

Vercel Analytics เก็บข้อมูลอะไร?

Vercel Web Analytics คือ aggregated traffic data แบบ privacy-friendly — เก็บ page view count, country (ไม่ใช่ IP), browser type, referrer. ไม่ใช้ cookies. ไม่ track individual user. ไม่เก็บ IP. ไม่ส่งไปที่ Google/Facebook. ไม่ใช้สำหรับ advertising หรือ remarketing วันเกิดของคุณ ไม่ส่งไปที่ Vercel Analytics — เป็น analytics ของ page navigation เท่านั้น
