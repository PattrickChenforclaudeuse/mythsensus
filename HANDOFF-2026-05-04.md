## Architecture you'll need to know

**Engine pipeline** (the live runtime path):
```
Mythsensus/report-engine/lib/{calc,report}.ts   ← edit here
   │ npm run build:engine
   ▼
Mythsensus/build/{calc,report}.js + ms26-bundle.js
   │ node Mythsensus/tests/inject-bundle-root.cjs   (into index.html)
   │ node Mythsensus/tests/inject-bundle.cjs        (into offline HTML)
   ▼
index.html + Offline app/mythsensus-offline.html
   between /* MS26_BUNDLE_START — auto-injected, do not edit */
       and /* MS26_BUNDLE_END */
```

The user-visible chart at mythsensus.com is generated by `window.MS26.calculate()` + `window.MS26.generateReport()` — both come from the inlined ms26-bundle. There are also INLINE copies of these functions in index.html outside the bundle markers — those are dead code (left over from before the bundle was inlined, never executed), do not edit them expecting changes to land.

**Deity pipeline**:
```
Mythsensus/report-engine/data/gods.json          ← canonical tiers + blessing_en/th
Mythsensus/build/gods-inline.js                  ← messages_en/th (different schema)
   │ node Mythsensus/tests/sync-gods-inline-tiers.cjs   (sync tiers from gods.json by index)
   │ node Mythsensus/tests/inject-gods-online.cjs       (inject into both HTMLs)
   ▼
index.html + offline HTML between /* GODS_FULL_START */ ... /* GODS_FULL_END */
```

The two files have DIFFERENT schemas: gods.json carries `blessing` strings (one per deity) for the daily rail; gods-inline.js carries `messages` arrays (multiple per deity) for Organum 108-vote. Both list 1,069 entries in the same order with one duplicate name ("Wakan Tanka" at indices 978 + 1059, different tiers each). Sync by INDEX, not by name.

## If the user reports a bug

1. **Reproducer first**. Get the birth date / time / lang / device (mobile vs desktop) so the bug is reproducible.
2. **Sanity test against the engine**:
   ```js
   const c = require('./Mythsensus/build/calc.js');
   const r = require('./Mythsensus/build/report.js');
   const chart = c.calculate({ year:..., month:..., day:..., hour:..., minute:..., lat:..., lon:..., timezone:..., lang:'th' });
   console.log(JSON.stringify(chart.score, null, 2));
   ```
3. If the engine is fine, the bug is in the inline app code (index.html outside the bundle). If the engine misbehaves, it's report.ts/calc.ts.
4. Run `fuzz-30-charts.cjs` and `fuzz-edge-cases.cjs` before committing any engine fix to confirm no regression.
