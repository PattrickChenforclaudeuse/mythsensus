- `localStorage.mth_purchased` — `{ "deep_western:e3a29ce6": "ISO-date", ... }`

## 🔑 Knowledge to carry forward

1. **The inline `<script>` in `index.html` is fragile to syntax errors** — a single unescaped apostrophe wiped out all inline `onclick` handlers across the entire site. **Always run the syntax check** after editing:

   ```bash
   node --input-type=commonjs -e "
   const fs=require('fs');
   const html=fs.readFileSync('index.html','utf8');
   const m=[...html.matchAll(/<script(?![^>]*src)[^>]*>([\\s\\S]*?)<\\/script>/g)];
   let big=m[0],bigLen=m[0][1].length;
   for(const x of m){if(x[1].length>bigLen){big=x;bigLen=x[1].length;}}
   try { new Function(big[1]); console.log('OK'); } catch(e){ console.log('FAIL: '+e.message); }
   "
   ```

   Watch for `\\'` inside template literals — that's the bug pattern. Use `\'` (single backslash) inside single-quoted inner strings, or rephrase to avoid apostrophes.

2. **Two source-of-truth surfaces for the report engine:**
   - `Mythsensus/report-engine/lib/{calc,report}.ts` — TypeScript source (canonical)
   - `Mythsensus/build/*.js` — compiled artifact used by the offline pipeline + sample HTML generator
   - **When fixing report bugs, edit the .ts and run `npm run build:engine`.** Don't patch the .js directly — it will be overwritten.

3. **Cosmic Score nomenclature:**
   - `score.soulFrequency` = `score.total` = median across all 26 systems (born-chart only)
   - `score.cosmicFinal` = SF×0.4 + LT×0.3 + PR×0.3 (or = SF when LT/PR are 0)
   - The hero "COSMIC SCORE" shows `cosmicFinal` as canonical.

4. **HD Authority is approximated** — without proper defined-center calculation, `pickHdAuthority()` deterministically picks one authority from the type's valid set. Real HD calc requires gates → channels → centers logic that's a future engine upgrade.

5. **`?login=1` deep-link** auto-opens the OTP overlay. Pattern reusable for other entry-overlay shortcuts.

6. **Per-input purchase hash is FNV-1a over normalised**: DOB + time + gender + city + name. Trivial whitespace/casing differences don't invalidate. Big enough to spot-check by eye but small enough to be readable.

7. **Library entries are kept even after the underlying chart input changes.** Old purchases show up under a "PAST CHART · revert inputs to view" banner. This is intentional — the user shouldn't lose history just because they edited their profile.

8. **`applyLang()` re-triggers the current panel renderer.** If you add a new dynamically-rendered panel that builds its HTML using `LANG === 'th' ? … : …`, no extra wiring needed — it'll re-paint on toggle automatically.
