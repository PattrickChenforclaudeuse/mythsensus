## 🔑 Key Knowledge for Next Session

1. **The inline `<script>` in `beta/index.html` is fragile to syntax errors** — a single unescaped apostrophe wiped out all inline `onclick` handlers across the entire site. Always run the syntax check above after editing.

2. **Two source-of-truth surfaces for the report engine:**
   - `Mythsensus/report-engine/lib/{calc,report}.ts` — TypeScript source
   - `Mythsensus/build/*.js` — compiled artifact used by other code paths
   - When fixing report bugs, **edit the .ts and rebuild**, don't patch the .js directly.

3. **Cosmic Score nomenclature** (clarified this session):
   - `score.soulFrequency` = `score.total` = median across all 26 systems (born-chart)
   - `score.cosmicFinal` = SF×0.4 + LT×0.3 + PR×0.3 (or = SF when LT/PR are 0)
   - The hero "COSMIC SCORE" now shows `cosmicFinal` as the canonical number.

4. **HD Authority is approximated** — without proper defined-center calculation, `pickHdAuthority()` deterministically picks one authority from the type's valid set. Real HD calc requires gates → channels → centers logic that's a future engine upgrade.

5. **`?login=1` deep-link** in `/beta/` auto-opens the OTP overlay — used by the new email button on the root landing page. Pattern is reusable for other entry-overlay shortcuts.
