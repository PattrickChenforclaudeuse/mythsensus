✦ Common Issues

App won't open or shows blank page

The app requires JavaScript. If you're viewing a zipped copy on iOS Files app, extract the zip first and open the .html file in Safari directly. Otherwise, try a different browser.

Report shows wrong information

Double-check the date, time, and birthplace in the Entry screen. A 1-hour time difference changes some systems (especially BaZi Hour pillar and rising sign). If the birth time is unknown, the app defaults to 12:00.

Gift code not accepted

Codes are case-sensitive and include the dash. Valid beta codes: MYTH-BETA, MYTH-IX, MYTH-VIP, MYTH-FRIEND, MYTH-PRESS, MYTH-TEST.

Feature request / feedback

We love feedback. Email us with your idea — concrete use cases and screenshots help us prioritize.
